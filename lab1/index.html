1. Введение и цели проекта

Современные веб-приложения требуют четкого разделения ответственности между бэкенд-сервисами и пользовательским интерфейсом. Данный проект посвящен проектированию и реализации масштабируемой системы планирования задач и целей.

2. Используемый стек технологий

  • Backend: C# (.NET Core Web API), Entity Framework Core
  • Frontend: React, TypeScript
  • База данных: PostgreSQL
  • Контейнеризация и безопасность: Docker, JWT (JSON Web Tokens)
